# 📊 Tableau Sales Dashboard

## Project Overview
An interactive **Sales & Profit Analysis Dashboard** created using **Tableau Public** to analyze sales performance, profitability, regional performance, and shipping trends.

## 🛠️ Tools Used
- Tableau Public
- Data Visualization
- Calculated Fields
- KPI Analysis
- Geographic Analysis

## 📌 Key KPIs

| KPI | Value |
|---|---:|
| Total Sales | 2,297,201 |
| Total Profit | 286,397 |
| Quantity | 37,873 |
| Profit Margin | 12.47% |
| Avg. Ship Time | 4 Days |

## 📈 Key Insights

- **Technology** is the highest-selling category.
- **West Region** contributes the highest sales share at **31.58%**.
- **California** is the top-performing state.
- Sales and profit show noticeable **monthly fluctuations**.
- Profit margin varies across months, highlighting opportunities for improvement.
- Shipping performance varies by **Ship Mode**.

## 💡 Recommendations

- Focus on high-performing categories and regions.
- Investigate low-performing regions and states.
- Monitor discounts to protect profit margins.
- Improve shipping efficiency and delivery performance.

## 📂 Dashboard Includes

- KPI Summary
- Sales & Profit by Category
- Monthly Sales & Profit Trend
- Profit Margin Trend
- Sales by Region
- Sales by State
- Shipping Analysis
